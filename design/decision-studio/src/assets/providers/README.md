# Provider marks

Ten unchanged SVGs from Simple Icons 14.15.0, retrieved from the npm registry on 29 September 2026. The archive was checked against its registry SHA-512 integrity value. Each SVG was inspected to contain only `svg`, `title` and `path` elements, with no event handlers or external references. No package JavaScript is executed or bundled.

The [manifest](provenance.json) records source URLs, upstream metadata and per-file SHA-256 values. The package [license](LICENSE.md) and [disclaimer](DISCLAIMER.md) are retained. Package licensing does not grant trademark rights. Marks identify example source mappings; they do not imply affiliation, endorsement or available/live integrations. The SVGs stay unchanged; CSS gives them a monochrome light treatment for legibility.

Provider text accompanies each informational mark. Decorative marks use empty alt text. Assets are served locally under the site's existing CSP. No logo service is called at runtime.
