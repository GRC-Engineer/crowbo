# Scholar colour study

Mode: built-in image generation, reference-guided colour edits and comparison layout.
Status: proposed colour options, not an adopted brand palette.
Input: ../scholar-iterations/comparison.png, using its top-right Terminal Scholar.
Output: comparison.png

The four portraits share ink-purple feathers, mint irises, dark pupils and pale eye whites. Only the glasses frame colour varies. Hex values below are prompt targets, not measurements of the generated image.

Use case: precise-object-edit and compositing. Asset type: one controlled colour-comparison sheet for the Crowbo mascot. The supplied image is a four-panel Scholar design sheet. Use ONLY the top-right crow labelled B / TERMINAL SCHOLAR as the character identity reference. Create a clean opaque 2-by-2 board of FOUR IDENTICAL head-and-shoulders portraits of that same crow. Same silhouette, pixel grid, crest, beak, glasses geometry, camera angle, eye direction, expression, size, lighting and feather colours in every panel. Crop each at the upper chest so the face and glasses are large enough to compare. We are testing colour alone, not four different personalities. Preserve the expressive intelligent round-glasses Scholar face, tousled three-feather crest, dark ink-purple plumage and slate-grey corvid beak. Use deliberate crisp pixel clusters, without blur, smoothing, glossy rendering or fine grain. All four portraits should look like copies of the same base sprite with only the spectacle frame colour swapped.

Shared palette in ALL four: deep ink-purple crow approximately #28243E, slate-purple feather shading, small clean mint highlights approximately #A4EDC3, warm ivory eye whites, near-black pupils. Change BOTH IRISES to mint green #A4EDC3, keeping their black pupils and visible pale eye whites so the eyes stay friendly and expressive. The green irises must be clearly visible inside every pair of glasses. No glowing eyes. Preserve the mint feather-edge accents from B sparingly and equally in all four; do not wrap the whole character in a luminous halo.

The ONLY variable between panels is the glasses frame colour: top-left A has warm copper #C57944; top-right B has vivid coral-orange #FF6A3D; bottom-left C has electric pink #FF4F91; bottom-right D has bright golden amber #FFC34D. Uniform frame thickness and geometry. Opaque coloured frames with clear colourless lenses so the green irises remain visible. Tiny lighter pixel accents in each frame's own hue are allowed; no metallic material change or lens tint between versions.

Presentation: square or slightly landscape polished retro-game art-direction sheet, two equal rows and columns, consistent ample padding, full crest and full beak visible in each portrait. Flat OPAQUE deep navy-black #10101B panel backgrounds, warm off-white header and gutters, clean thin dividers. Completely solid backgrounds throughout; this is a finished opaque comparison graphic, not transparent cutouts or a checkerboard. Clean any accidental coloured fringe or speckle. A narrow title area says exactly 'CROWBO / COLOUR STUDY'. Small subtitle says exactly 'MINT EYES / FOUR FRAME COLOURS'. Beneath each portrait use a readable monospaced caption: 'A / COPPER', 'B / CORAL', 'C / PINK', 'D / AMBER'. Beneath each caption place three small square colour swatches: the shared ink-purple, the shared mint, and that panel's frame colour, in that order. No other text, no hex-code lettering, no logo, watermark, props or environment. This should make the tradeoff between restrained copper and flashy coral/pink/amber immediately obvious, while all versions clearly remain the same beloved Scholar crow.
